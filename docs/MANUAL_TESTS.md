# Windows / Outlook実機確認

以下は**未実施**です。実施時はOutlookの版・ビルド・32/64bit、Windowsの版、メールアカウント種別、対象コミット、実際の結果を記録してください。

実際の送信を伴う項目は、自分が管理するテスト用メールアカウント・配布リストだけを使います。

| ケース | 操作 | 期待結果 |
|---|---|---|
| ビルド | Build Toolsだけでtest.ps1とbuild.ps1 -Publishを実行 | テスト成功、署名済みDLLマニフェストと.vstoを生成 |
| 導入 | Outlookを閉じ、install.ps1を実行後に起動 | COMアドイン一覧に表示され、有効になる |
| To/Cc/Bcc | それぞれ異なるテスト宛先を設定して送信 | 全件が正しい種別・名前・SMTPアドレスで表示される |
| 明示承認 | 「送信する」を押す | 1通だけ送信され、確認ウィンドウは再表示されない |
| キャンセル | 「キャンセル」を押す | 送信トレイ・送信済みに入らず、編集を継続できる |
| Esc / × | それぞれで閉じる | キャンセルと同じ |
| 既定ボタン | 確認ウィンドウを開いた直後にEnter | 送信せずキャンセルされる |
| 再試行 | キャンセル後、宛先を変更し再度送信 | 最新の一覧で再確認される |
| インライン返信 | 閲覧ウィンドウ内から返信・送信 | 確認が表示される。キャンセル後に編集できる |
| 別ウィンドウ | 独立したメール編集ウィンドウから送信 | 確認ウィンドウが前面に出る |
| キーボード送信 | Outlookの送信ショートカットを使用 | 同じ確認を経由する |
| Exchangeユーザー | 社内ディレクトリからユーザーを選択 | Exchange内部DNではなくSMTPアドレスを表示 |
| SMTP別名 | 別名アドレスを宛先に指定 | Outlookが実際に保持している宛先アドレスを表示 |
| Exchange配布リスト | テスト用グループを指定 | グループアドレス、グループ表示、未展開の注意書き |
| 個人用連絡先グループ | 未展開で送信、その後Outlookで展開して再試行 | SMTP解決不能なら中止。展開後は全エントリーを表示 |
| 未解決宛先 | 解決できない名前を入力して送信 | Outlook自身またはアドインが送信を止める |
| オフライン | キャッシュあり/なしのExchange宛先で試す | アドレスを確認できない場合に無確認で送信しない |
| 宛先多数 | 100件以上、長い表示名/アドレスを使う | 全件数が一致、縦横スクロールと全文欄で確認可能 |
| DPI | 100%/150%/200%で表示 | ボタン・一覧・説明が操作できる |
| 確認中の変更 | テスト用自動化で確認ダイアログ表示中に宛先を変更 | 「送信する」後に変更検知で送信中止 |
| 再入 | 確認ダイアログ表示中に別の送信イベントを発生 | ネストした送信を許可しない |
| 他アドイン | 他アドインが先にCancel=trueにした送信を試す | このアドインがCancel=falseへ戻さない |
| 非メール | 会議依頼を送信 | このアドインは確認を表示しない |
| 再起動 | Outlookを再起動してメール送信 | 購読が有効で毎回確認する |
| 削除 | Outlookを閉じてinstall.ps1 -Uninstall | 対象アドインが解除される |

Outlook 32bit / 64bitはそれぞれ別環境で検証します。本実装はAnyCPUであり、32bit版と64bit版のOutlookへ同一のマネージドDLLを使用する設計ですが、両方の実機検証が必要です。
